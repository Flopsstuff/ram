# Open Knowledge Format (OKF) v0.2

`SPEC.md` is a verbatim copy of the OKF specification that the vault follows.

- **Source:** [`GoogleCloudPlatform/knowledge-catalog`, `okf/SPEC.md` at `62432a0`](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/62432a0/okf/SPEC.md)
  (2026-08-21, the v0.2 text with the timestamp amendment).
- **License:** Apache License 2.0, the same as this repository. Copyright belongs to the
  specification's authors.

The vault's own `_conventions.md` files carry the rules agents need while writing (`type` per
folder, `description`, `status` for lifecycle only, `state` for workflow, reserved `index.md`
and `log.md`). This file is the full reference behind them.

To update: replace `SPEC.md` with the upstream file and change the commit above.
